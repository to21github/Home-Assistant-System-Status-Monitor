# 更新日志

## 1.2.3

- 优化：基础镜像换用 python:3.11-slim，镜像体积约缩小 800MB，减轻 SD 卡空间压力
- 优化：gunicorn 收敛为单 worker，内存占用约减半，并消除多 worker 重复采集
- 优化：Supervisor 回退请求超时从 5s 对齐至 2s
- 修复：移动端标题与副标题间距恢复为与网页端一致，副标题与运行时间卡片间距减半

## 1.2.2

- 维护性版本更新

## 1.2.1

- 界面：标题改为左对齐，新增副标题"Home Assistant 系统运行状态及健康评分"
- 新增：标题右侧手动刷新按钮，刷新时图标旋转指示

## 1.2.0（正式版）

- 安全：移除不必要的 host_network 网络授权，仅保留 Supervisor API 所需权限
- 性能：Supervisor 请求超时从 5s 收紧至 2s，避免无响应时长时间阻塞仪表盘
- 修复：HA 延迟为 0ms 时误显示"无数据"
- 依赖：升级 Flask 3.0.3 / psutil 6.1.1 / requests 2.32.3 / gunicorn 23.0.0（含安全修复）
